# Underline: центральный указатель проекта

Это входная точка. Если нужно что-то найти, начни здесь.

## Что это
**Underline** (рабочее название): пошаговая игра об одной станции метро Нью-Йорка после Тишины. Ты держишь станцию на линии Кони 40 недель, распределяешь людей и ресурсы, разговариваешь с лидерами пяти сил и по осколкам узнаёшь, почему замолчала поверхность. Движок Godot 4.7.

## Состояние на сейчас
- Версия для тестеров: **0.1.0-playtest8** (закрытый плейтест на itch.io, Windows).
- Играбельно: станция, карта сети, 5 лидеров с аудиенциями и озвучкой (110 строк EN/RU), 25 жителей с досье и историями (озвучены), 3 бункера, 8 концовок, 14 новых событий пула, помощь лидерам, первые подсказки.
- Ждём: журналы и анкеты тестеров (форма отчёта, `docs/playtest/BUG_REPORT_TEMPLATE.md`).
- Активная цель: одна, выбранная по данным плейтеста (см. `docs/IDEAS_PARKING.md`, раздел «В работе сейчас»).

## Как работаем
1. **Один активный набор задач на агента.** Новая идея это одна строка в парковке.
2. **Всё локально.** Не пушим и не загружаем без слова владельца.
3. **Каждый код проходит 8 гейтов** и идёт отдельным коммитом по теме.
4. **Тексты пишет руководитель.** Без тире, никто не улыбается, без реальных символов.
5. **Озвучка, арт, крупный код только после «в работу» владельца.**
6. После каждого пакета: строка в `docs/DECISIONS.md`, при необходимости `node .tools/changelog.js` и отчёт исполнителя в `docs/audit/` или в чат.

## Как обновлять этот указатель
Когда появляется новый документ, дописать строку в таблицу «Где что лежит». Когда меняется состояние, обновить раздел «Состояние на сейчас». Резервную копию папки проекта (без `build/` и `.godot/`) стоит делать вручную раз в несколько дней: репозиторий с историей лежит только на этом диске.
