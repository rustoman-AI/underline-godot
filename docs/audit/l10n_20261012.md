# Localization audit EN/RU, 2026-10-12

Two passes:

- **Static** (`node .tools/l10n_audit.js`): reads every EN/RU pair in data/ and every `Copy.t` / `_note` / `_label` / `_button` literal in sim/ and ui/, writes build/l10n/findings.json.
- **Runtime** (`godot --headless --path . -s res://.tools/l10n_runtime.gd -- --lang=ru|en`): plays 5 bot styles x 4 seeds with the station UI loaded and words every waiting event, choice, lock reason, morning line, intent line, audience and help reason, journal row and ending title the way the UI does. Flags Latin words in Russian, Cyrillic in English, raw ids and dashes. Writes build/l10n/runtime_<lang>.json.

## Checked, not a bug

- Plurals RU: all `Words.count` / `Copy.plural` paths give correct forms; the 6 static hits are handled forms.
- Plurals EN: "You helped recently, %d weeks left" has a separate 1-week branch; "Only %d to %d weeks" is a range; "(%d stories heard)" is always 3 or more.
- "People %d free" and "Missing art" are English branches of RU/EN splits or dev-only text; `_job_text` / `_short` in station.gd are dead code.
- Journal titles "Pay", "Address", "Gift", "Aid: ..." appear only in bot runs: the player UI has no buttons for these orders, so no player sees them. If those orders ever get UI buttons, `network_view._order_title` needs titles for them.
- events_checks banners and events_leaders needs.leader are ids, not shown. stations.json `desc` and `full` are not read by the UI.
- INTENT lines: the "INTENT " tag is stripped by `_intent_row`; only the station names inside are English (see below).
