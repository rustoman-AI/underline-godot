# Soak test, 2026-10-12

Bot profile careful, each style over its seeds for up to 40 weeks. In every run the game is saved to disk and loaded into a fresh game of another seed at three random weeks (half at dawn right after the autosave point, half after the turn's actions, like a manual save); the loaded copy then plays the same bot for 5 weeks and its whole exported state is compared with the uninterrupted run after every week. Invariants are checked every week; script errors and warnings are caught with a Logger.

Total time 19.0 min summed over the styles; one process per style in parallel, about 3 min wall clock. 1400 runs, 4200 save and load round trips, 21000 compared weeks after a load.

The tables below are the final run on the fixed code (commit 8c76a16), English. Re-run on 83a6824 after the later fixes: 1400 runs, 0 failures, same endings; save fuzz 2429 cases, 0 bad. The same 1400 runs were also played in Russian before the fixes for language-independent checks (text emptiness in RU): 0 failures besides the bug below.

## What the soak found

- **Loaded games drifted from the uninterrupted run** (first seen: storyteller seed 1, dawn save at week 6, `stock.air` differs at the end of week 9; seed 2, save at week 12, `gen_down` at week 14). 3 of the first 3 seeds tried failed. Cause: `_offer_checks` set `opened` on the catalog's own check event, and the catalog is shared by every game in a session (New Game and Continue reuse it). After a check had opened once, its `effects_on_open` (brownout, vent cut) never applied again in that session. Fixed in 28f8355 with a regression test in check_save (same seed twice on one catalog). After the fix: 0 of 1400.
- **Orphan flags (false alarm, check corrected)**: `counting_heard = true`. Flags set by events are `true` by design (`flags[flag] = true` in three places), not a week number. The soak now flags only values that are neither `true` nor a week up to the current one, and names that appear nowhere in data or code.
- The soak also checks that the catalog is unchanged after each run (hash of every catalog field), which would catch the same class of bug elsewhere: 0.

## Observations for the lead (no change made)

- No careful-bot run ends in a loss: the five non-story styles all reach week 40 (`winter`). Storytellers end at week 34 (180 of 200), 35 (18) or 36 (2) with open_door, exodus or order. Not a bug; worth knowing when reading balance numbers.

## Reproduce the whole soak

One process per style (they run in parallel), then the merge:

```
.tools/godot/Godot_v4.7.2-stable_win64_console.exe --headless --path . -s res://.tools/soak.gd -- --styles=<style> --seeds=200 --from=1 --weeks=40 --keep=8
.tools/godot/Godot_v4.7.2-stable_win64_console.exe --headless --path . -s res://.tools/soak.gd -- --report
```
