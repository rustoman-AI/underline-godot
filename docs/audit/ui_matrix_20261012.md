# UI matrix EN/RU, 2026-10-12

Tool: `.tools/ui_matrix.gd`, one windowed run per language and size, one at a time:

    godot --path . -s res://.tools/ui_matrix.gd -- --lang=ru --size=1366x768

Shots: shots/qa/<lang>_<WxH>/ (not committed). Findings: build/ui_matrix/<lang>_<WxH>.json.

**Matrix:** 2 languages x 7 sizes (1280x720, 1366x768, 1600x900, 1920x1080, 2560x1440, 3440x1440, 1024x768) x 15 screens = 210 shots. Every run printed the real window and image size; all matched the requested size. Full matrix: 294 s, no script errors.

**Screens:** main menu, settings, how-to, new game, station week 1, People panel, event with 3 choices, audience card with 3 buttons, network map, station sheet, station week 25, journal, Truth page, final decision, epilogue.

**Checks on every visible control of the topmost open layer:**

- outside the window, or off screen;
- squeezed below its minimum size;
- text cut (trimmed, or lines hidden);
- poking out of its container (rotated paper sheets are skipped);
- text contrast measured on the shot pixels (1st vs 99th percentile luminance under the text, flag below 2.2:1);
- Latin in RU, Cyrillic in EN, raw ids, em/en dashes, raw log tags (BATTLE, ULTIMATUM...).

Custom-drawn text (the yard canvas, the map canvas) is not a Control and is checked by eye in the shots only.

## For the lead (art, colour or design, not changed)

1. **Red alert chip on the event card is hard to read**: dark red text on dark paper, 1.9 to 2.0:1 at every size ("⚠ Exchange wants 24 tokens, 2 turns left"). Needs a lighter red or a light chip background.
2. **Locked approach orders on the station sheet** ("Approach the Floor", "Подойти к «Карантину»", "Подойти к Обсерватории"): grey reason text on grey, 2.1 to 2.2:1. Readable at 1080p, faint at 1440p.
3. **Journal season line** ("Cold season started." / "Начался сезон: холод.") is muted on paper, 2.0:1 at 1440p.
4. **No automatic UI scale for big screens.** At 100% the UI is drawn in native pixels, so at 2560x1440 and 3440x1440 body text is about 14 px on a 27-34 inch screen. Nothing is cut or overlaps; players can pick 125% or 150% in Settings. Choosing a default scale by screen height is a design call.
5. **Hub art missing in this working copy** (assets/hubs/hub_coney_island.webp, only the .import file exists). Without it New Game skips the start screen and goes to the dawn report, and the main menu and settings have no backdrop, so the station HUD shows through behind the "Settings" title. If the file ships in the build this does not happen; worth checking the build.
6. EN ultimatum chip says "2 turns left" while the rest of the UI says "weeks". Wording.

## Not bugs

- People panel, audience card, network and journal at every size: no overflow or clipping found.
- 3440x1440 ultra-wide: the yard widens, chrome stays anchored, nothing stretched or cut.
- First run flagged about 100 contrast hits; almost all were controls hidden under an open card or menu, or short words in wide rows. The tool now checks only the topmost layer and measures only the inked part of a label.
