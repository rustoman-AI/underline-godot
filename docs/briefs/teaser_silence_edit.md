## Запись

```
godot --path . --resolution 1920x1080 --fixed-fps 30 --write-movie build/teaser/teaser_en.avi res://tools/teaser/teaser.tscn -- --lang=en --stills
```

`--stills` сохраняет контрольные кадры в `build/teaser/stills_<lang>/`.
Пока голоса Muse нет, строки идут только субтитрами. Когда в `incoming-audio/teaser-vo-01/ogg/` появятся файлы `teaser_silence_<n>_<lang>_take1.ogg`, голос подхватится сам: нужно просто перезаписать ролик.

Скриншоты из игры снимаются так: `.tools/map_size_shots.gd -- --lang=<en|ru> --size=1920x1080 --tag=teaser`. Результат: `shots/map_size/teaser/`.

AVI пишется в MJPEG. Для Steam и Shorts его нужно перегнать в MP4 (H.264) в DaVinci Resolve, CapCut или ffmpeg. Вертикальную версию 9:16 делаем там же, с центральной кадровкой.
