# Underline: рамка игры и проверка новых идей (v1, 12 октября 2026)

Зачем: любое добавление (нити, детектив, доставки) должно ложиться на то, что игра уже есть, и не ломать её логику. Все цифры ниже сверены с репозиторием (данные и код), а не придуманы.

## 2. Для кого игра (целевая аудитория и профиль игрока)
- Игроки Frostpunk, This War of Mine, Papers, Please, Fallout Shelter и Crusader Kings: любят моральные выборы без правильного ответа, читают тексты, готовы к 2–4 часам.
- Не для тех, кто ждёт экшен, строительство базы в реальном времени, сложную боёвку.
- Эмоциональный профиль: тревога, ответственность, редкое тепло. Не гротеск, не юмор ради юмора.
- Ядро удовольствия: «я решил, и люди запомнили» (последствия), «я догадался» (улики), «я не мог иначе» (серая мораль).

## 3. Правила для добавлений (защита от поломки логики)
1. **Не добавлять новых валют и ресурсов.** Только существующие: воздух, еда, энергия, материалы, жетоны, влияние, надежда, недовольство, отношение лидера.
2. **Не больше 4 решений в неделю.** Новые системы приходят вместо части старых слотов, а не поверх. Всё необязательное можно пропустить без потери концовки.
3. **Всё в данных (JSON), детерминированно по seed.** Нить это данные плюс сохранённое состояние, а не код под каждый случай.
4. **Каждое добавление проходит:** сохранение и миграцию, EN и RU, покрытие ботом (достижимость), валидацию данных, баланс-гейт.
5. **Не ломать сюжетный костяк:** осколки правды, три бункера, три концовки остаются главными. Нити второстепенны и дополняют.
6. **Тон:** серьёзно, без смакования насилия, без улыбок, без реальных символов и партий. Описание убийств, увечий и пыток не показывается.
7. **Озвучка только по моей команде,** после окончательного текста.
8. **Не называть ничего из чужого сеттинга.** В игре нет «Золотого Века», «Вандалов», «Шоутайма», газа «Дольче», MTA как фракции. Это из другого мира.

## 5. Единая модель нити (чтобы любые линии добавлялись одинаково)
Нить это запись данных:
- `id`, `title` (en, ru), `intro` (en, ru);
- `participants`: жители (ids) и при необходимости лидер;
- `culprit` или `answer`: для детективных нитей выбирается при старте из списка `candidates` (в сохранении);
- `clues`: список улик `{id, kind (belonging, route, rumour, photo, voice), source (dossier field, event id, item), text (en, ru), points_to (id или список)}`;
- `unlock`: условия, когда улика открывается (прочитан раздел досье, прослушана история, событие, неделя);
- `resolve`: действие «Назвать имя» или выбор, с исходами (верно, неверно, не успел) и последствиями (надежда, недовольство, отношения, флаги, одна строка в эпилог);
- `epilogue`: одна-две строки для итогового экрана.
Состояние в сохранении: открытые улики, выбранный `culprit`, исход. Тестируется ботом (достижимость исходов), валидируется загрузчиком (все ids существуют, тексты на двух языках).

## 6. Проверка «глазами»
- Досье сейчас (скриншот Night Moon): фото, имя, **профессия** (добавлена в этих правках), навыки (Закалка, Смекалка, Голос, Чутьё), кнопка «Остановить историю», «Своими словами», «До тишины», «Вещь», «Альбом», «Память», «События». На экране 1280x720 вертикальная прокрутка уже есть.
- Куда ложится триада: после «Вещь» два новых раздела, **«Маршрут»** (цепочка станций) и **«Слухи»** (две-три строки), только у подозреваемых нитей (6–8 жителей из 25, не у всех).
- Эскиз карточки:
```
Досье                             [Закрыть]
[фото]  Пит Наваро, мастер на все руки
        Закалка 3 · Смекалка 1 · Голос 0 · Чутьё 0
Вещь:    Одна кровельная плитка
Маршрут: Канал-стрит, Грин-пойнт, Хай-стрит
Слухи:   «Говорят, на Хай-стрит по ночам кто-то
          ходит у вентшахты.»
```
- Место для вердикта: кнопка «Назвать имя» на странице «Нити», не в досье.
- Что надо проверить после реализации: помещаются ли три блока в EN и RU на 1280x720 и 1024x768 (матрица экранов ночного QA уже включает досье).

## 7. Что решаем сейчас
1. Принять рамку (разделы 1–3) как постоянный документ: любое новое предложение проверяется по таблице раздела 4.
2. Не начинать нити до первого круга плейтеста (смотрим, читают ли игроки досье).
3. Продолжаем заполнять досье (вкладки, маршруты, слухи) для всех 25: это основа и для нитей.
4. Night Moon может писать улики и слухи для 6–8 подозреваемых по модели из раздела 5: файл `data/threads/` будет готов, когда движок дойдёт.
